### 为什么这次反转?归因

**根因 1:预测目标改变**(核心)
- 上次:预测 5min K 线 token,信号=预测涨幅 top-10
- 本次:仍预测日 K 线 token,但**信号=预测超额收益**(剥离指数 beta)
- 模型被迫学横截面 alpha,而非"均值回归形态"

**根因 2:数据量充足**
- 上次:5min 数据仅 4 个月,80 个交易日
- 本次:日线数据 2.5 年,614 个交易日
- 微调降幅 6.8% → 42%

**根因 3:评估指标修正**
- 上次:只看 Val Loss(被误导)
- 本次:主指标是超额 RankIC(直接对应选股能力)

## 3. 信号有效性诊断

### 3.1 为什么胜率 40% 但 RankIC 高?

```
胜率 = top-K 平均超额 > 0 的日子占比
RankIC = 预测排序 vs 实际排序的相关性
```

胜率低但 IC 高意味着:
- 模型不是"每天都选对股票"
- 但模型**排序能力强**:top-K 平均跑赢中位数
- 个别极端日(市场普跌)拖低胜率,但 IC 不受影响

**实盘启示**:RankIC 比 胜率更重要,组合分散(top-K 而非 top-3)能平滑单日波动。

### 3.2 [待全量验证] IC 衰减

需全量回测后计算 lag-1/3/5 日 RankIC,判断信号有效期。predict_window=5,若 lag-5 仍 > 0.5×lag-0,信号有效期足够。
