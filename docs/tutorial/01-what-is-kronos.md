# 01 — 什么是 Kronos

> 目标:读完这篇你会知道 Kronos 是什么、它解决了什么问题、为什么有人觉得它能用来炒股。

---

## 一个类比:Kronos 是"K 线界的 GPT"

你大概听说过 ChatGPT。它的工作方式是:

```
输入一段文字: "今天天气真"
GPT 预测下一个字: "好"
继续: "今天天气真好,我们去"
GPT: "公园"
```

GPT 把文字切成一个个"token"(词的碎片),然后预测下一个 token。

**Kronos 做的是一模一样的事,只不过把"文字"换成了"K 线"**:

```
输入一段历史 K 线: [红绿红绿红...]
Kronos 预测下一根 K 线: [绿(下跌)]
继续预测: [红(上涨)]
```

这就是为什么 Kronos 的论文标题是 *"A Foundation Model for the **Language** of Financial Markets"* —— 它把金融市场当成一种"语言"来学。

---

## 但 K 线怎么变成 token?

文字天然是离散的(一个字就是一个字),但 K 线是连续的数字(开盘价 95.76、收盘价 96.20...)。GPT 没法直接吃连续数字。

Kronos 的核心创新是一个叫 **Tokenizer** 的组件,它做"翻译":

```
连续 K 线: 开盘=95.76, 最高=96.50, 最低=95.20, 收盘=96.20, 成交量=100万
      ↓ (Tokenizer 编码)
离散 token: token_42  (代表"小幅上涨、低波动"这类形态)
```

这个过程是**可逆**的 —— 也能从 token 解码回 K 线(`token_42 → 开盘=95.8, 收盘=96.2...`)。

> 💡 想深入 Tokenizer 原理(BSQ 量化器),看 [架构文档:tokenizer](../architecture/tokenizer.md)

## Kronos 的两件套

```
┌─────────────────┐         ┌──────────────────┐
│   Tokenizer     │         │    Predictor     │
│                 │         │                  │
│  K 线 ↔ token   │  token  │  GPT 风格预测    │
│  (翻译官)       │ ──────→ │  下一个 token    │
│                 │         │                  │
└─────────────────┘         └──────────────────┘
       ↑                            ↑
   可逆翻译                    自回归生成
```

1. **Tokenizer**:把每根 K 线编码成 2 个 token(主语义 + 残差细节)
2. **Predictor**:一个 GPT 风格的 Transformer,给定历史 token 序列,预测未来 token

预测完之后,用 Tokenizer 把未来 token **解码回 K 线**,就得到了"未来走势的预测"。

---

## 为什么大家觉得它能用来炒股?

Kronos 的论文报告了一些亮眼数字:

- 训练数据:全球 45+ 交易所,**120 亿根 K 线**(跨股票/期货/加密/外汇)
- 价格预测的 RankIC 比之前最好的时序模型提升 **93%**
- 波动率预测的误差降低 **9%**

听起来很厉害。所以一个自然的想法是:

> "既然它能预测 K 线,那我预测出未来 5 天的 K 线,挑出'预测涨幅最大'的几只股票买入,不就能赚钱了吗?"

**这就是我们这两次实验想验证的思路。** 结果证明这个思路有个根本性的漏洞 —— 但那是后面的故事了。

## Kronos 的三档模型

HuggingFace 上有三档开源权重:

| 模型 | 参数量 | 上下文长度 | 我们用的 |
|---|---|---|---|
| Kronos-mini | 4M | 2048 | |
| Kronos-small | 25M | 512 | |
| **Kronos-base** | **102M** | **512** | ✅ 这个 |

我们用 base(最大开源版),精度最高。

---

## 关键限制

- **max_context = 512**:输入历史 K 线不能超过 512 根。对日线约 2 年,对 5 分钟线约 5 个交易日
- **预训练数据是全球市场**:A 股只是其中一小部分,可能需要"微调"才能适应 A 股的特性
- **官方声明不是生产系统**:作者明确说这只是研究用途,不是可以直接拿来赚钱的工具

---

## 小结

Kronos = "把 K 线当语言学的 GPT"。它能预测未来 K 线形态,听起来能用来选股。**我们的实验就是验证这个想法是否成立。**
