# 03 — 怎么验证:为什么"loss 低 ≠ 能赚钱"

> 目标:这是**最重要的一篇**。读完你会理解为什么"模型预测准"和"能用来选股赚钱"是两回事,以及什么是 RankIC。
>
> 这一节的认知,是我们两次实验最大的收获。

---

## 第一个坑:Val Loss 的迷惑性

### 什么是 Val Loss?

训练 AI 模型时,我们盯着一个数字叫 **loss(损失)**。它衡量"模型预测得有多不准":

```
loss 低 = 模型预测准
loss 高 = 模型预测不准
```

训练的目标就是让 loss 降下来。这听起来很合理 —— 模型越准越好嘛。

### 实验 1 的迷惑

第一次实验(5min)训练后,Val Loss 从 2.35(预训练 zero-shot)降到 **2.19**(降幅 6.8%)。

我们当时想:"loss 降了这么多,模型应该学会预测 A 股了"。然后满怀期待地跑回测,结果:

```
4 折合并 80 天累计收益: -32.55%
夏普比率: -3.79
胜率: 40%
```

**稳定亏损。** loss 明明降了,为什么不赚钱?

### 真相:loss 衡量的东西,和我们要的不是一回事

Kronos 的 loss 衡量的是:**token 重建误差**(预测的 K 线 token 和实际 token 差多少)。

```
loss 低 = "预测的 K 线形态像实际的 K 线形态"
         ≠
        "能挑出哪只股票明天涨更多"
```

打个比方:一个画师能临摹出和原画几乎一样的画(loss 低),但你让他选"哪幅画以后会升值",他可能完全不会选(没赚钱能力)。

**这两个任务是不同的**。这是我们花了一次实验才搞明白的核心认知。

---

## 第二个坑:累计收益的迷惑性

### "累计收益正"也可能靠运气

你可能想:"那看累计收益不就行了?赚钱就是好策略。"

实验 2 的 fold1/fold2 回测结果:

```
fold1: 累计超额收益 +16.1%  ← 看起来赚钱!
fold2: 累计超额收益 +16.6%  ← 也赚钱!
```

但仔细看它们的 **RankIC**(下面解释)是**负的**。这意味着:

```
策略确实在这段时间赚了钱,但不是因为"选股准"
而是因为整个市场都在涨(市场 beta),运气好赶上了
换个时间段,同样的策略可能就亏
```

这和实验 1 的 "v1 fold1 假盈利" 是同一种陷阱 —— **累计收益会骗人**。

---

## 正确的指标:RankIC

### 什么是 RankIC?

**RankIC(排名相关系数)** 衡量的是:

> "模型预测的股票排名" 和 "实际涨跌排名" 有多一致

具体说,每天模型给 100 只股票打分(预测涨幅),排出名次。然后看实际涨跌,也排出名次。算这两个排名的相关性。

```
RankIC = +1   完美:预测第一名,实际也是第一名
RankIC = 0    随机:预测和实际无关(瞎猜)
RankIC = -1   反向:预测第一名,实际是最后一名
```

### 为什么 RankIC 比 loss 和累计收益都好?

1. **直接衡量选股能力**:RankIC 高 = 模型真的能区分"好股票"和"差股票"
2. **不受市场涨跌影响**:就算整个市场暴跌,只要模型选的股票相对抗跌,RankIC 也能高
3. **不受运气影响**:累计收益可能靠一次大行情,RankIC 看的是每天的稳定性

### 行业基准

A 股量化圈的经验值:

| RankIC | 评价 |
|---|---|
| < 0.02 | 无效(随机)|
| 0.02 ~ 0.05 | 弱 alpha(勉强可交易)|
| 0.05 ~ 0.10 | 中等 alpha(不错的策略)|
| > 0.10 | 强 alpha(很罕见)|

我们实验 2 设的门禁是 **RankIC > 0.03**(弱 alpha 起点)。

---

## 我们改进的评估方法

基于实验 1 的教训,实验 2 建立了一套**正确的评估框架**:

### 1. 主指标用超额 RankIC,不用 Val Loss

```
每日计算: Spearman(预测超额收益排名, 实际超额收益排名)
折内取均值
```

### 2. 必须看所有折,不只看最优模型

实验 2 训练了 5 个模型(4 折 CV + 全量 full)。如果只看 full(最优),会得到 RankIC 0.034(刚过门禁)—— 看起来不错。但看 4 个单折,**全部 ≤ 0**。真相是"模型没学到稳定 alpha"。

### 3. sample_count=1 最保守

Kronos 推理时可以多次采样取均值(sample_count)。实验初期我们用 sample_count=20,得到 RankIC 0.079(看似远超门禁)。后来换成 sample_count=1(单次贪心),RankIC 跌到 0.034 —— **采样平滑会高估能力**。

### 4. 累计收益 + RankIC 对照看

```
累计收益正 + RankIC 正 = 真 alpha ✅
累计收益正 + RankIC 负 = 假 alpha(运气/市场 beta)❌
累计收益负 + RankIC 负 = 模型反向(也算信号,反转用)🤔
```

实验 2 的 fold1/fold2 就是"累计收益正 + RankIC 负"的典型假 alpha。

---

## 这套方法学的价值

说实话,这两次实验**没做出赚钱的策略**。但建立了一套**不会被自己骗到的评估方法**,这比一次偶然赚钱更有价值:

- 实验 1 因为只看 loss,被误导了,以为"模型学会了"
- 实验 2 用 RankIC,立刻看穿了"模型其实没学会选股"

**如果你要做类似的量化实验,直接复用这套评估框架**:

```python
# 核心评估逻辑(伪代码)
for each_validation_day:
    predictions = model.predict(all_stocks)  # 预测每只股票
    actual_returns = ...                      # 实际超额收益
    daily_rankic = spearman(predictions, actual_returns)

mean_rankic = average(daily_rankic)  # 这才是主指标
# 不要只看 model.val_loss 或 cumulative_return
```

---

## 小结

- **Val Loss 低 ≠ 能赚钱**:loss 衡量"形态预测准",和"选股能力"是两回事
- **累计收益正也可能靠运气**:要看 RankIC 是否也为正
- **RankIC 是正确主指标**:直接衡量横截面选股能力,不受市场涨跌影响
- **要看所有折 + 用 sample_count=1**:避免被最优模型或采样平滑欺骗
