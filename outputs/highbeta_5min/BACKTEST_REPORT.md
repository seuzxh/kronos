> 回测日期: 2026-07-18
> 模型: full (全量训练, Val Loss 2.1964)
> 回测方式: 日级调仓(基于5min预测), 每日开盘前预测当日走势, 选top-10等权, 开盘买入收盘卖出

## ⚠️ 核心结论: 策略亏损, 不具备实战价值

**4折合并80天: 累计收益 -10.15%, 夏普 -0.92, 最大回撤 -11.96%**

模型预测准确度(Val Loss)虽优于zero-shot, 但**未能转化为超额收益**。

## 2. 为什么预测"准"(Val Loss低)却不赚钱?

### 根本原因: 信号方向对但幅度不够, 且噪声大

```
模型学到: "预测5min K线形态" (Val Loss 2.19, 优于zero-shot 2.35)
     ↓ 但
实际需要: "选出明天涨最多的股票" (排序能力)
```

- **Val Loss衡量的是"K线形态预测误差"**, 不是"涨跌幅排序能力"
- 模型可能把每只股票的5min走势都预测得"形态相似"(平均预测), 导致排序接近随机
- 高贝塔股本身波动剧烈, 信噪比极低, 预测难度大

### 其他可能原因

1. **信号设计粗糙**: 用归一化空间的预测close排序, 没还原到真实涨幅
2. **未对比基准**: 没算超额收益(vs 沪深300或等权全池), 可能是大盘普跌
3. **手续费侵蚀**: 0.1%单边×每天换仓, 20天吃掉4%收益
4. **持仓周期不匹配**: 预测的是"次日全天走势", 但开盘买入收盘卖出只吃日内, 没吃到预测的跨日部分

## 3. fold1 为何盈利?(正向案例)

fold1(2026-04~05)是唯一盈利折(+6.62%, 夏普3.10):
- 可能该时段**高贝塔股有持续性**(涨的继续涨), 适合趋势跟随
- 或该时段市场单边上行, 选股容错率高
- 这说明**模型在某些市场状态下是有alpha的**, 需要状态识别

## 4. 改进方向(优先级排序)

### 🔴 高优先级(可能根因)

1. **改进信号生成** (当前最大问题):
   - 现状: 用归一化空间预测close排序
   - 改进: 还原到真实价格, 计算真实预测涨幅 = `pred_close末 / lookback_close末 - 1`
   - 这是最可能的bug点

2. **计算超额收益** (vs 基准):
   - 当前是绝对收益, 大盘跌时全跌
   - 需对比沪深300或等权全池100只的平均收益

3. **调整持仓周期匹配预测目标**:
   - 预测的是"次日全天", 应该前日收盘买入、次日收盘卖出(T+1)
   - 当前是当日开盘买入收盘卖出(日内), 没对齐

### 🟡 中优先级

4. **微调tokenizer**: 当前用预训练的, 可能在5min分布上量化误差大
5. **多信号融合**: 不只用close, 结合预测的high/low/volume做综合打分
6. **增大top-K或降低换手**: top-10每天全换手续费高, 试top-20或加持仓粘性

### 🟢 探索性

7. **市场状态过滤**: 只在fold1类(趋势市)交易, 震荡市空仓
8. **组合优化**: 加入波动率约束、行业分散等
