## 2. 观察与分析

### ✅ 正面信号
1. **Val Loss 单调下降**, 无过拟合迹象(epoch1-8 持续改善或持平)
2. **收敛稳定**, epoch7-8 持平说明已达当前配置的学习极限
3. 训练耗时合理(38分钟/折), 4折+最终约3-4小时可全部完成

### ⚠️ 需关注
1. **Val Loss 降幅很小** (-0.85%), 可能原因:
   - 预训练模型本身已较好(zero-shot 2.35 → 微调 2.19)
   - 5min 走势本身噪声大, 信噪比低(高贝塔股波动剧烈)
   - tokenizer 用的是预训练的(未在5min数据上微调),可能限制下游predictor效果
2. **Train Loss 波动大** (2.20~2.50), 高方差:
   - 高贝塔股池每日换手84只, 样本异质性高
   - batch=32 单batch内股票差异大
3. **Epoch 6-8 train loss 出现2.47/2.50高点**, 但val loss 仍下降 → 模型在泛化

### 💡 后续可尝试的改进方向
1. **微调 tokenizer** (当前用预训练的): 在5min数据上训练tokenizer, 可能提升下游效果
   - 命令: `KRONOS_FOLD=0 bash run_cv.sh` 中先跑 train_tokenizer
2. **增大 n_train_iter**: 当前每epoch仅64000样本(占1.23亿窗口的0.05%), 增大可能有益
3. **调整 LR**: 当前 predictor_lr=3e-5, OneCycleLR max=3e-5. 可尝试更小LR(1e-5)或更大(1e-4)
4. **更长 lookback**: 当前240(5天), 可尝试480(10天)捕捉更长趋势
